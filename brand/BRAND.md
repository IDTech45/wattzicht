# Wattzicht huisstijl

**Naam:** Wattzicht ("zicht op je watts"). Woordmerk: **Watt** vet, zicht regular.
**Beeldmerk:** een oog (zicht) met de zon als iris en een bliksem als pupil (watt). Werkt in één kleur, in donker en licht.

## Kleuren

| Token | Hex | Gebruik |
| --- | --- | --- |
| `night` | `#0F172A` | Primaire merkkleur, tekst, donkere achtergronden |
| `night-soft` | `#1E293B` | Kaarten in dark mode |
| `sun` | `#F59E0B` | Accent: zonopwek, CTA-knoppen |
| `sun-light` | `#FFD166` | Gradient-partner van sun |
| `battery` | `#22C55E` | Thuisbatterij, succes |
| `grid` | `#3B82F6` | Netstroom, laadpaal |
| `export` | `#A855F7` | Teruglevering |
| `ink` | `#111827` | Hoofdtekst (light) |
| `muted` | `#64748B` | Subtekst |
| `paper` | `#F8FAFC` | Pagina-achtergrond (light) |
| `card` | `#FFFFFF` | Kaarten (light) |
| `danger` | `#DC2626` | Storing, fout |

Energiestromen krijgen altijd dezelfde kleur, in de app én op de site: zon = sun, batterij = battery, net = grid, teruglevering = export.

## Typografie

Inter (web), systeemfont op mobiel (SF Pro / Roboto). Koppen 700–800, lopende tekst 400.

## Toon

Jij-vorm, kort, geen jargon. "Zie wat je bespaart" in plaats van "monitoring-dashboard".
