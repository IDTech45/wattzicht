Die laatste staat erbij om naast de Wattzicht-pagina's te leggen: zelfde navy koppen, zelfde witte
kaarten met de navy kaartschaduw, zelfde fonts, zelfde donkere paneel met een gekleurd getal erin.
Het enige dat verschilt is het accent: daar groen, hier geel.

De donkere website-opname is gemaakt door de `prefers-color-scheme: dark`-regels uit de echte
stylesheet toe te passen, niet door ze over te typen. De waarden zijn dus precies die van de site.
